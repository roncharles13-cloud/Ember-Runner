Single-stream RSSI from your laptop's WiFi card. Presence & motion are reliable; breathing resolves only when a subject is close to the link and still. The spectrogram and phase portrait are latent axes — extra dimensions recovered from the same 1D signal by math alone (short-time FFT + Takens delay-embedding): a still breather traces a clean loop and lights the low band; walking smears the portrait into a cloud and spreads energy upward. For pose/silhouette you still need CSI hardware — the pipeline is built to accept it. Start with python -m wifi_sense --source synthetic to see it move.

WiFi-Sense · sensor comparison

Three ways to feel the same room

One identical scene — empty → still & breathing → walking → empty — seen through three different sensors, all running the same pipeline. Read down each column: the raw signal, its micro-Doppler spectrogram, and its delay-embedding phase portrait. Read across to see how differently each sensor perceives the very same events.

Shown here from each sensor's simulated mode (this box has no mic, radio, or LiDAR). On real hardware the same commands drive the same columns — LiDAR sharpens markedly, since it emits its own probe.

Signal strength to your router. Nearly flat when the room is empty, jittery when someone's near, wild swings when they cross the link. The spectrogram is faint and smeary (low signal-to-noise) and the phase portrait is a loose blob — passive RSSI is noisy. Great for “someone’s here / moving,” weak on fine detail.

Same idea as WiFi, on the Bluetooth radio — tracking a nearby advertiser’s signal strength. Coarser and noisier (BLE updates slower and quantizes hard), so presence and gross motion read fine but breathing is unreliable. Treat it as a second, independent radio channel.

The only sensor whose raw value is a real distance in metres. The line drops from ~3.2 m (empty far wall) to ~1.4 m when a person stands close — occupancy you can read as depth. Its phase portrait sits in a different place for “person near” vs “empty,” carrying coarse position no RF sensor here has. iPhone/iPad Pro only.

What the columns reveal: every sensor nails presence and motion, but they carry different information. WiFi & BLE are passive signal-strength — coarse, noisy. LiDAR is the only one whose raw value is a real distance — its phase portrait separates "person at 1.4 m" from "empty wall at 3.2 m," carrying coarse depth no RF sensor here can.
